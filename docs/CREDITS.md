# クレジットとライセンス

ゲームに同梱する外部アセット（モデル・モーション・画像・音・フォントなど）と、その出典・ライセンスを記録する。
記録のないアセットは使ってはいけない（CLAUDE.md「絶対ルール」参照）。

| アセット | ファイル | 作者・出典 | ライセンス | 備考 |
|---|---|---|---|---|
| ミラ（ヒロインの 3D モデル） | `public/models/mira.vrm` | tk（VRoid Studio 2.14.0 で自作。パーツは VRoid Studio 標準のプリセットのみ） | VRM 1.0 の利用条件（下記） | 再配布・改変は禁止。このゲームへの同梱のために置いている |

### ミラ（`mira.vrm`）の利用条件

VRM ファイルのメタ情報（VRM 1.0）に書き込んだ内容と同じ。コードとは別に、このモデルにはこの条件が適用される。

| 項目 | 設定 |
|---|---|
| アバターとして使える人 | 作者のみ |
| 暴力表現での利用 | 禁止 |
| 性的表現での利用 | 許可 |
| 商用利用 | 個人の非営利のみ |
| 政治・宗教での利用 | 禁止 |
| 反社会的・ヘイト表現での利用 | 禁止 |
| クレジット表記 | 不要 |
| 再配布 | 禁止 |
| 改変 | 禁止 |
